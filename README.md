# Exapfx Web App

## App Demo:
https://exapfxweb.vercel.app/

You can view the application directly in the browser.

Exapfx Web App is a web application focused on presenting structured data through a clean and simple interface. The emphasis is on visual organization and clarity, allowing users to easily understand the content without additional interaction.

## Display
Structured data overview
Clear information hierarchy
Minimal and clean design
Focus on readability and layout
